# CRUD Application

## Description
This is a simple CRUD (Create, Read, Update, Delete) application where users can manage records. It features the basic operations for adding, viewing, editing, and deleting items, making it an ideal starting point for learning how to manage data in a web application.

## Features
- Create, read, update, and delete records.
- Responsive design for various devices.
- Simple and intuitive user interface.

## Technologies Used
- **Frontend**: React, Tailwind CSS
- **Backend**: JSON Server (mock API for data management)
- **Hosting**: Local development using Vite

## Prerequisites
Before you begin, make sure you have the following installed:
- [Node.js](https://nodejs.org/)
- [JSON Server](https://github.com/typicode/json-server)
